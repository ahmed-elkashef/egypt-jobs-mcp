# Original native AUBI-plus readers

The anonymous read-only inventory follows the provider's public GET form and
numbered/forward controls at https://www.aubi-plus.de/suchmaschine/suche/.
Country is explicitly the native deutschland choice. Scopes are all,
student_internship (studentenpraktikum), and working_student (werkstudent).
There is no career/degree/employer keyword or personal commute limit.

Initial pages carry only scope. Continuation requires page, first_page_total
and the exact continuation_url advertised by the previous native view. Indexed
array aliases, empty source search/default controls, country, selected model,
highlighted page and native URI all reconcile. The dormant25km source default
has zero/empty location fields and is not a personal radius. Changing counters
refuse; there is no retry/reset/completion fiction.

Preserve all visible offers and their native company-group context, including
namespaced IDs and overlapping rows. Never calculate pages from count/anzahl.
The provider labels its counter Plaetze; the relationship with distinct advert
URIs is unqualified. A terminal is the observed href# control with an empty
forward-page label and disabled parent, without contradictory later numbers.

Student labels do not certify a university internship: current examples include
EQ, school/retraining and study-funding contexts. The unfiltered complement
includes an internship/thesis namespace absent from the student view. Qualified
observed advert routes are ausbildung, duales-studium, schuelerpraktikum,
praktikum, werkstudium, abschlussarbeitsthema and job. Other namespaces require
qualification; they are not silently discarded or requested as arbitrary URLs.

Public adverts bind exact kind/ID/canonical/OpenGraph. Strict UTF-8 HTTP HTML
provides the complete native header card, stellenbeschreibung body, sidebar
facts and separately published application-information panel. Related offers,
account/share/bookmark controls, navigation and source scripts are excluded.
Nontext media, employer originals and actual application-form materials remain
separate checks. No application form, map, source script, media, subscription,
contact, account, payment or cookie/session request is made.

Published JSON-LD can contain literal control characters. Valid published
objects and strict parse-error diagnostics/hashes remain separate; malformed
fragments are never repaired or promoted into dates/eligibility. The shared
native bridge preserves a validated source_limited result on exit2 only when
source identity, null count and non-promoting flags match. Other failures and
failed success-looking payloads retain the generic error boundary.

The implementation is original; only published protocol/data observations and
synthetic regression fixtures are included. Native capture metadata is dated
engineering evidence, never a source/employer/country/week census or fit verdict.
