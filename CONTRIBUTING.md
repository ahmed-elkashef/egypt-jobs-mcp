# Contributing

Add national sources under the matching country package and cross-country implementations under shared/packages. Update the source registry, retain original credits and add synthetic failure/continuation/full-text tests. New backend tools must also be explicitly reviewed into the federation allowlist.

Run root checks and all retained Python/Node suites. Live probes must be bounded, distinguish source denial from zero jobs, and never run automatically in CI. Do not commit job datasets, private applicant state, credentials, browser sessions or account configuration.
