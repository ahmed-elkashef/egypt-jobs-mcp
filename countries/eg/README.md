# Egypt

Egypt's reusable source package is independent of an individual applicant's hours, education, location, preferences or review threshold. National acquisition can cover full-time, part-time and other genuine native models. Personal rules belong in the consuming private application.

[MCP code](mcp/) exposes WUZZUF, Forasna, ArabJobs, Tanqeeb, Akhtaboot and Bayt routes, public DOM parsing/receipt verification, native WUZZUF taxonomy and verified browser recipes. [Python adapters](../../packages/source-adapters/) preserve existing imports and CLI names. Shared remote/ATS/client-project tools are exposed once under `shared_`.

WUZZUF uses blank-query Egypt JSON:API enumeration plus authoritative resource hydration; API card offsets and public browser page indexes are different. ArabJobs retains country/type/newest query and real continuation. Forasna/Tanqeeb retain authorized native browser traversal where HTTP is denied/empty; filter membership must be verified on returned cards, not inferred from a selected checkbox or URL. Akhtaboot requires an actual native empty state. Bayt card summaries/access limits do not establish complete job descriptions.

The path is source capabilities → native inventory → complete description → immutable evidence → duplicate/clock reconciliation → consumer review. The reusable code never decides personal fit or publishes candidate evidence. A `source_limited` response is unfinished acquisition, not an empty Egyptian market.

Outstanding country branches include official labour bulletins/government vacancies, additional national/regional boards, universities/student channels and a maintained employer-directory census. [sources.json](../../sources.json) records each separately. Informal, closed and offline hiring remains an explicit coverage boundary. The existing implementation and saved access evidence must not be represented as a census of all Egyptian opportunities.

Legacy MCP: `node countries/eg/mcp/index.mjs` (or root `index.mjs`). Unified MCP: root `server.mjs`, tools prefixed `eg_` and `shared_`.
