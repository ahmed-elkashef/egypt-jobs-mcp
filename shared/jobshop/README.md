# Original Jobshop SSR and CMS career reader

Original anonymous code for the independently identified Fraport career origin,
`https://www.jobs-fraport.com`. The public front is talentsconnect/Jobshop; its
separate SuccessFactors profile link is not proof of a SAP RMK API contract.
Other custom origins require independent qualification before support is added.

## Read-only operations

- `shared_jobshop_capabilities`: offline contracts and verified origins.
- `shared_jobshop_inventory({career_origin})`: the complete native SSR link
  array, native anchors/titles and independent whole-board count. No role,
  location, language, category, candidate or pagination selection is accepted.
- `shared_jobshop_detail({job_url})`: an exact returned canonical UUID or
  public `offer-redirect` URI. Follow only actual advertised same-company and
  qualified public vendor redirects, after each origin's robots policy check.

The current `/search` embeds a complete `ssrJobLinks-...-search` reference array
in inert Nuxt JSON. The homepage independently advertises `typesenseJobCounts`.
The reader follows only selected bounded JSON references, never executes source
code and never resolves or uses the unrelated temporary scoped search key.
Every URI/title must reconcile with an actual native anchor and the independent
total. A placeholder translation, a partial array or moving count is an explicit
limit. Canonical UUID and opaque legacy references remain separate source
identities until their complete body UUID/alias facts can be reconciled.

## Complete primary body and context

The native `JobPosting` may omit description entirely. Its `jobData.description`
and other text fields may also be empty while the CMS renders a complete advert.
The reader requires the complete primary `section.job-data-section`, matching
hero title, native offer UUID and source schema identifier. It preserves its
whole HTML/text, every top-level CMS section, and full main HTML/text separately.

The main/context export removes forms, scripts, styles and controls; the complete
primary job section remains intact. Testimonials/company marketing are context,
not automatically additional requirements. Native form text is separate data
for process review; no value is entered and no application request is made.
Source HTML/text is not a browser-visible or independently reviewed body.

Whitelisted job fields, public contact facts and source schema remain available.
Hydration envelopes, temporary search credentials, unused credential settings
and embedding vectors are not exported. No search key, account API, source
script/CDN, application, contact or subscription request is implemented.

## Identity, clocks and eligibility

Native UUID, opaque offer reference, external employer identifier and human
reference remain separate. The public vendor redirect is followed only when
actually advertised, with its same reference, employer vanity and false
application-form flag. No vendor route is guessed or rewritten. Redirected
original external IDs must reconcile with the final native job fields.

Source `educationRequirements` can contain a work-model label; do not treat that
as an academic qualification. Creation/update/start/status clocks and schema
`datePosted`, `jobStartDate`, `validThrough` remain raw evidence. A generated
long expiry is not a verified deadline, and none becomes an original publication
instant, student contract, Germany-based remote permission or individual fit.

Each call checks policy; denied/challenged/error routes stop. Robots 404/410 is
qualified as unavailable under RFC9309. Redirected robots responses are refused.
Whole responses above 8 MiB are refused; output budgets never clip a body. Each
native request has a 10-second timeout and the IPC call has a 55-second ceiling.
No source-wide or historical completeness is implied by a current employer
snapshot or successful source acquisition.

Standalone: `python shared/jobshop/reader.py --capabilities`, then exact
`--career-origin https://www.jobs-fraport.com` or returned `--job-url`.

## Frozen qualification, 30 October 2026

The actual unified MCP reconciled all 115 current native references (22
canonical UUID and 93 legacy redirect links) and obtained 115 complete primary
CMS bodies with 115 distinct resolved offer UUIDs. All 115 source schemas
omitted description. One native title had double spaces while its rendered
heading collapsed whitespace; only comparison is normalized and raw titles
remain intact. That advert was re-read after the fix; the other 114 bodies
were preserved without repeat requests. The initial refusal remains evidence.

The [aggregate proof](../../docs/jobshop-live-proof.json) records 124 actual
read-only MCP calls, the repaired source case, four compatible earlier readers
and two expected scope refusals. Thirty new Python and five Node tests cover
source counts, complete CMS, credential exclusion, legacy/native IDs, robots,
advertised redirects, clocks and malformed data. All 588 repository tests pass
locally. This dated employer qualification is not historical/country coverage
or applicant fit. No raw advert or applicant corpus is published here.
