This is an original MCP wrapper maintained by Ahmed Elkashef. It is not a
GitHub fork. The source feeds and the dependencies below make it possible.

  `@mambalabsdev/ats-scrapers` 0.1.0, Mamba Labs, ISC. Used as an unmodified npm

  Amit Kumar and contributors, MIT. Parses and validates Personio XML.

The package lock records exact dependency versions and distribution integrity.

applies to its original wrapper, tests and documentation.
